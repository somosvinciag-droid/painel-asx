# Painel ASX

App para a central multimídia Android do Mitsubishi ASX do Leonardo.

- **Comandos de voz** (sem internet): abrir apps, câmera de ré, volume, música, voltar, tela inicial, tocar em botões pelo texto.
- **Rotina ao ligar o carro**: volume, app de música (com play) e app de GPS.
- **Diagnóstico**: lista os apps da central e anota que telas ela abre (por exemplo, quando engata a ré).
- **Atualiza sozinho**: a cada envio para o `main`, o GitHub monta uma versão nova e o app instala sozinho.

## Instalar pela primeira vez

Na central, abrir no navegador:

https://github.com/somosvinciag-droid/painel-asx/releases/latest/download/painel-asx.apk

Depois, no app: **Ligar controle (Acessibilidade)** e **Permitir atualizações automáticas**.
